# World Adventure marking rules

These rules apply to each country question in Easy, Medium, and High.

## Calculate one question

**Question points = correct-answer points − (3 × wrong answers).**

The correct-answer points depend on how many clues have been shared when the correct answer is given:

| Clues shared | Correct-answer points | With 1 wrong answer | With 3 wrong answers |
| ---: | ---: | ---: | ---: |
| 0 | 10 | 7 | 1 |
| 1 | 8 | 5 | −1 |
| 2 | 6 | 3 | −3 |
| 3 | 4 | 1 | −5 |
| 4 | 2 | −1 | −7 |
| 5 | 1 | −2 | −8 |

A wrong answer costs **3 points whenever it is made**, including before the first clue. Each of the three incorrect choice buttons can be selected only once in a question. In High mode, each submitted wrong typed guess also counts as a wrong answer; an empty submission does not. The timer and clue count do not change because of a wrong answer. Asking Pip for a clue counts as receiving that clue and changes the correct-answer point tier.

The automatic answer reveal after five clues has **0 correct-answer points**. Any wrong-answer deductions from that question still apply: with no wrong answers its score is 0; with two wrong answers it is 0 − (3 × 2) = **−6**.

## Worked cases

| What happened during one question | Calculation | Question points |
| --- | ---: | ---: |
| Correct immediately | 10 − 0 | 10 |
| One wrong choice, then correct before a clue | 10 − 3 | 7 |
| First clue, then correct | 8 − 0 | 8 |
| First clue, three wrong choices, then correct | 8 − (3 × 3) | −1 |
| Two clues, one wrong typed guess, then correct | 6 − 3 | 3 |
| Five clues, three wrong choices, then correct | 1 − 9 | −8 |
| One wrong choice, then automatic reveal | 0 − 3 | −3 |

The signed question result is added to the running **Adventure total**, which can therefore rise or fall. For example, an existing total of 12 followed by a question worth −1 becomes **11**; a following immediate correct answer worth 10 becomes **21**. Each new question resets its wrong-answer count. Changing levels keeps the Adventure total; a fresh start or page refresh resets it. Discovery stars still count countries discovered and are never deducted.
