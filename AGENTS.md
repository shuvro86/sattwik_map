# Project maintenance

- Read `docs/PROJECT.md` before changing this application.
- After every project change, update `docs/PROJECT.md` in the same task. Keep functionality, files, sources, setup, tests, limitations, and the dated change log accurate. This is an explicit request from the project owner.
- Preserve a child-friendly experience for Sattwik (age four), four choices in every level, randomized country order, and a maximum of five clues with 30-second intervals by default.
- Preserve reduced-motion, keyboard, pause/visibility behavior, volume/mute controls, map-source credits, photo authors/licenses, and dated population sources.
- Do not add tracking, accounts, paid integrations, or public deployment without the owner's approval.
- Run `npm test` (no dependency installation needed) and syntax checks for modified JavaScript. For visual or interaction changes, check a phone-sized and desktop browser view.
- Verify all 195 country records and at least ten distinct country-specific photo records per country after changing datasets. Do not substitute unrelated images or duplicate photos to fill a gallery.
